# Security policy

Griffin runs agents that can call real tools, so we take reports seriously.

**Please do not open a public issue for a vulnerability.** Report it privately through
[GitHub's private vulnerability reporting](https://github.com/paziresh24/Griffin/security/advisories/new).
Include what an attacker can do, the steps to reproduce, and the version or commit.

We aim to acknowledge reports within a few days and to ship a fix or mitigation as soon as we have
confirmed the issue. Please give us a reasonable window before disclosing it publicly.

Especially interesting: ways for a caller to reach a tool it was not granted, for the model process
to see a credential, or for an unattended run to perform an action that needs approval.
