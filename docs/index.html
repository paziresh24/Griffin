Architecture & Security

Designed so CTOs and Security Teams can say yes

Safety in Griffin is enforced in isolated container boundaries and Broker code — never left to an LLM promising to behave.

Privilege-Separated Broker

The model never touches your raw credentials

The main App and Sandbox container holds zero passwords, SSH keys, or kubeconfigs. Credentials stay inside a separate Broker container (or your Infisical vault) reachable only over a local Unix socket with typed tool calls.

  • Automatic secret scrubbing on every tool response before reaching the LLM
  • SQL queries execute inside read-only transactions by default
  • Destructive or mutating actions pause in code until the owner taps Approve
