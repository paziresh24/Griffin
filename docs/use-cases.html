What you can build with Griffin

One install, several agents, each with its own job, tools and permissions. These are the setups Griffin is used for today; each one is a profile you can import and edit.

Griffin on GitHub Quick start

Personal assistant

Reads and sends Telegram messages on your behalf when you ask, keeps notes, and turns recurring requests into scheduled jobs that report back to your chat.

Research agent

Reads and compares sources you give it, separates what a source says from what it concludes, and never changes anything.

Writing agent

Drafts, edits, summarises and translates — Persian and English — without sending anything anywhere.

Team assistant

Colleagues message it on Telegram; it opens a thread only for real work, answers with your tools and its own limits, and asks you before anything irreversible.

Scheduled reports

A prompt, a schedule and a destination: daily numbers, a weekly digest or a chart, delivered to the chat where people already are.

Backend for coding agents

Claude Code, Claude Desktop or Cursor delegate long tasks to Griffin over MCP and pick up the answer when it lands.

Operations agent

Connected to your own systems through typed tools — databases, storage, CI, servers — with credentials kept out of the model.

Ready-made agent profiles

The repository ships importable profiles in examples/agents/: a personal assistant, a writer, a researcher, and operations examples. Import one from the agents page and change its instructions, model and tools.
