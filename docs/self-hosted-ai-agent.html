A self-hosted AI agent platform you control

Griffin runs a small team of AI agents on your own server. Agents are rows in a table, not code: instructions, a model, a set of tools, and a list of who may call them — with no SaaS control plane in the middle.

Griffin on GitHub Quick start

What you get

Agents as data

Create, edit and import agents from the web UI, the HTTP API or a JSON profile. Nothing about an agent needs a deploy.

Per-caller permissions

The owner, another agent, a scheduled job, a Telegram colleague and an external MCP client each get exactly the tools granted to them, enforced before tools reach the model.

Any model

Claude Agent SDK, Cursor SDK, or any OpenAI-compatible endpoint — Z.ai, OpenAI, or a local model — chosen per agent and per chat, with fallback on plan limits.

Delegation

An orchestrator agent delegates to specialists without blocking and reports back when subtasks finish.

Every interface

Web UI (right-to-left aware), terminal client, Bearer HTTP API, MCP endpoint, Telegram and Bale bots, scheduled jobs — or fully headless.

Rehearsal mode

Simulation chats run the whole delegation tree but record side effects instead of executing them, with scenario evals.

Runs on one small box

Node 24 and SQLite, one docker compose up. A fresh install is a chat with one agent and no infrastructure at all; tool packs for Kubernetes, PostgreSQL, Grafana, S3, GitLab and routers switch on only when you configure them.

Self-hosted, open source, MIT

  • Your data, prompts and credentials stay on your server.
  • Owner login is local and keeps working when your SSO is down.
  • The code is MIT licensed and has no telemetry or hosted dependency.
