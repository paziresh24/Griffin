# Code of conduct

We want Griffin to be a welcoming project for everyone, whatever their background or experience.

- Be respectful and assume good intent. Critique code and ideas, not people.
- No harassment, insults, or discriminatory language, in any language.
- Keep discussions on topic and help newcomers find their way.

Maintainers may remove comments, issues or contributions that break these rules, and may block
repeat offenders. Report problems privately to the maintainers through
[GitHub](https://github.com/paziresh24/Griffin/security/advisories/new) or by contacting a maintainer
directly.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
